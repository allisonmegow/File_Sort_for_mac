# File_Sort_for_mac
I download a ton of files often. Often it's for projects for bioinformatics, where it's critical I sort my files for easier, cleaner runs. You can adjust this for literally any file type, any folder. Go and be great! This is for mac users, I made this on Tahoe. I made the readme.txt for my friends, but this read me is exactly the same.

# Step one
Download and extract the zip. Click on the workflow and open in automator.

# Step two
Move workflow to ~/Library/Workflows/Applications/Folder Actions

# Step three
Ctrl+click on desired folder in (yourname) location. SELECT Services > Folder Action Set up.

# Step four
Click ok. Tick the boxes for the appropiate workflow for the appropriate folder.

# Step five
You're done! This will start working as soon as new files are downloaded, so let 'er rip!
